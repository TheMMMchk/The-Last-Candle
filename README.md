# The-Last-Candle <https://themmmchk.itch.io/the-last-candle>
## Игра для gamejam'а под названием Easyjam

Когда тьма поглощает всё, остаётся лишь свет свечи.

Ты — призрак, затерявшийся в стенах древнего замка.
У тебя осталась только одна свеча — твой единственный путь к свободе.
Но свет тает с каждой секундой...

The Last Candle — короткая атмосферная инди-игра, созданная за 7 дней для EasyJam.

Здесь время — это свет. Каждый миг, каждое движение, каждое столкновение с тенью уносит часть свечи.

* 🔦 Исследуй старый замок.
* ⚙️ Решай простые загадки.
* 👁️ Избегай теней, что тянутся к твоему свету.
* 🚪 Найди выход — или останься навечно во тьме.

🕯️ Последняя свеча горит. Что ты выберешь: страх или надежду?
